# RPA Bot สำหรับบันทึกข้อมูลพฤติกรรมเข้าสู่ระบบ RMS

## ใช้งานแบบง่าย (แนะนำ)

หลังตั้งค่าครั้งแรกเสร็จ (ดูหัวข้อ "ตั้งค่าครั้งแรก" ด้านล่าง) การใช้งานประจำวันมีแค่นี้:

- **ทดสอบ**: ดับเบิลคลิก `run_bot_dryrun.bat`
- **รันจริง**: ดับเบิลคลิก `run_bot.bat`

ไม่ต้องเปิด PowerShell พิมพ์ `$env:...` อีกเลย เพราะรหัสผ่านทั้งหมดเก็บไว้ในไฟล์
`.env` ที่ตั้งครั้งเดียวจบ โปรแกรมจะอ่านไฟล์นั้นเองอัตโนมัติทุกครั้งที่รัน

## ภาพรวมการทำงาน

```
ครูกรอกฟอร์ม (React) -> GAS -> ชีต "Records" (RMS_Sync_Status = "pending")
                                          |
              ดับเบิลคลิก run_bot.bat (หรือ Task Scheduler รันให้อัตโนมัติ)
                                          |
         บอท login เข้าเว็บแอป EDMS (อ่านรหัสผ่านจากไฟล์ .env) -> ได้ token
                                          |
              ดึงคิว -> ทีละรายการ: login RMS -> ค้นหา -> เช็ก REF tag ซ้ำ
                        -> กรอกฟอร์ม -> บันทึก -> อัปเดตสถานะ + log ทันที
                                          |
        สถานะใน Records: synced / needs_review / error
        ประวัติทุกครั้งที่รัน: ชีต "RPA_Log" (สร้างอัตโนมัติ) — ดูได้ว่าสำเร็จ/
        พลาดตอนไหน ใช้เวลาเท่าไหร่ต่อรายการ (ข้อมูลนี้ใช้ในบทที่ 4 ของงานวิจัยได้เลย)
```

## การป้องกันข้อมูลซ้ำ

ทุกรายการที่บอทบันทึกจะฝัง `[REF:<uuid>]` ต่อท้ายช่อง "รายละเอียด" ใน RMS เสมอ
ก่อนบันทึกทุกครั้งบอทจะค้นหา REF tag นี้ในตาราง "พฤติกรรม" ของนักเรียนคนนั้นก่อน
— ถ้าเจอแปลว่าเคยบันทึกไปแล้ว จะข้ามทันที ไม่บันทึกซ้ำ

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

```bash
pip install -r requirements.txt
playwright install chromium
```

### 1. อัปเดต Google Apps Script
วางเนื้อหาทั้ง 7 ไฟล์ (`Config.gs`, `Main.gs`, `Service_Auth.gs`, `Service_PDF.gs`,
`Service_Records.gs`, `Service_Users.gs`, `Utils.gs`) ทับของเดิมใน Apps Script
Editor แล้วรัน `setupSyncColumns()` หนึ่งครั้ง จากนั้น **Deploy -> Manage
deployments -> ไอคอนดินสอ -> เปลี่ยน Version เป็น "New version" -> Deploy**

### 2. สร้างไฟล์ .env (แทนการตั้ง environment variable ทุกครั้ง)
คัดลอกไฟล์ `.env.example` เป็นชื่อ `.env` (เอา `.example` ออก) แล้วเปิดด้วย Notepad
กรอกค่าให้ครบ 4 ค่า:

```
RMS_APP_USERNAME=rpa-bot
RMS_APP_PASSWORD=รหัสผ่านบัญชี rpa-bot ที่สร้างในหน้า "จัดการผู้ใช้งาน"
RMS_BOT_USERNAME=บัญชีสำหรับล็อกอิน RMS จริง
RMS_BOT_PASSWORD=รหัสผ่านของบัญชีนั้น
```

เซฟแล้วปิด — เสร็จแล้ว ไม่ต้องตั้งค่าอะไรผ่าน terminal อีกเลยตลอดไป

### 3. สร้างบัญชีบอท 2 บัญชี (คนละระบบกัน)
- ในเว็บแอป EDMS: login ด้วยบัญชี Admin -> "จัดการผู้ใช้งาน" -> เพิ่มบัญชี `rpa-bot`
- ใน RMS จริง: ขอผู้ดูแลระบบสร้างบัญชีเฉพาะสำหรับบอท (ไม่ใช้บัญชีคนจริง)

### 4. ยืนยันข้อความฐานความผิด 9 หมวดที่เพิ่งเพิ่มใน RMS
เปิด `offense_mapping.py` แก้ `match_text` ของรายการที่เป็น `"PENDING_NEW"` ให้ตรง
กับข้อความจริงที่พิมพ์ไว้ใน RMS แล้วเปลี่ยนเป็น `"HIGH"`

## ตั้งให้รันอัตโนมัติเต็มรูปแบบด้วย Windows Task Scheduler

1. Task Scheduler -> Create Basic Task -> ตั้งความถี่ (เช่น ทุก 15 นาที)
2. Action: Start a program
   - Program: path ของ `run_bot.bat` (ใช่ครับ ตั้งให้รันไฟล์ .bat ได้เลย ไม่ต้อง
     เรียก python.exe ตรงๆ อีกต่อไป เพราะไฟล์ .env จัดการ credential ให้แล้ว)
3. **ไม่ต้องตั้ง environment variable ระดับ System อีกแล้ว** (เมื่อก่อนต้องทำ
   เพราะยังไม่มีไฟล์ .env) — นี่คือข้อดีอีกอย่างของการเปลี่ยนมาใช้ .env
