# RMS Bot Control — UI Redesign Handoff

ไฟล์อ้างอิง: `RMS Bot Control.dc.html` (เปิดดูได้ในเบราว์เซอร์ พร้อม `support.js`)

## วิธีใช้กับ Claude Code

1. ดาวน์โหลดโปรเจกต์ (zip) แล้วแตกไฟล์ไว้ในโฟลเดอร์โปรเจกต์เดิมของคุณ เช่น `design/`
2. เปิด Claude Code ที่โฟลเดอร์โปรเจกต์ แล้ววางพรอมป์ต์ด้านล่าง

### พรอมป์ต์ที่แนะนำ

> ปรับ UI ของโปรแกรม RMS bot (ไฟล์ `<ชื่อไฟล์ .py ของคุณ>`) ให้ตรงกับดีไซน์อ้างอิงใน `design/RMS Bot Control.dc.html`
> (เปิดไฟล์นั้นอ่านโครงสร้างและค่าสีได้เลย) และสรุปสเปกใน `design/HANDOFF.md`
> ห้ามเปลี่ยน logic การทำงานเดิม — แก้เฉพาะชั้น UI
> ใช้ CustomTkinter แทน tkinter.ttk เดิม และคงชื่อฟังก์ชัน/ตัวแปรที่ผูกกับปุ่มไว้เหมือนเดิม
> ทำทีละส่วน: (1) โครง layout 2 คอลัมน์ (2) ฟอร์มตั้งค่า (3) แผงรันบอท (4) คอนโซลล็อก

## โครงหน้าจอ

- **Header**: โลโก้สี่เหลี่ยม 42px + ชื่อระบบ + คำอธิบายย่อย, ขวาสุดเป็น status pill (เขียว = พร้อมทำงาน, เหลือง = กำลังรัน)
- **คอลัมน์ซ้าย — ขั้นตอนที่ 1 ตั้งค่าบัญชี**
  - แบ่ง 2 กลุ่ม: “เว็บแอป EDMS” และ “บัญชี RMS จริง”
  - label เล็กอยู่ **เหนือ** ช่องกรอก (ไม่ใช่ข้างซ้าย)
  - ช่องรหัสผ่านมีปุ่ม แสดง/ซ่อน อยู่ **ในช่อง** ด้านขวา (ไม่ใช่ checkbox ข้างนอก)
  - กล่อง hint สีครีม + ปุ่ม “บันทึกการตั้งค่า” ชิดขวา พร้อมข้อความสถานะการบันทึกด้านซ้าย
- **คอลัมน์ขวา — ขั้นตอนที่ 2 รันบอท**
  - Segmented control 2 ตัวเลือก (ทดสอบ / รันจริง) บนพื้น `#f4f1ef`, ตัวที่เลือกเป็นพื้นขาว + เงาบาง
  - ข้อความเตือนใต้ segmented เปลี่ยนตามโหมด (โหมดจริง = สีส้ม)
  - ปุ่มรันเต็มความกว้าง เปลี่ยนเป็น “หยุดการทำงาน” (พื้นเทา) ขณะรัน
  - Progress bar สูง 6px + ตัวนับ `done / total (%)`
  - **คอนโซลล็อก** พื้นมืด สูง ~236px ฟอนต์ mono มี timestamp และสีแยกระดับ: ปกติ `#c9c3d0`, สำเร็จ `#7fd1a8`, เตือน `#e8b04b`; ปุ่ม “ล้าง” / “บันทึกไฟล์” ที่หัวการ์ด

## ถ้าทำต่อด้วย Python

- แนะนำ **CustomTkinter** (ใกล้เคียงดีไซน์นี้ที่สุด และแก้จากโค้ด tkinter เดิมได้ง่าย)
- ถ้าต้องการมุมโค้ง/เงา/ฟอนต์ตรงเป๊ะกว่านี้ ใช้ **PySide6 + QSS** หรือห่อหน้าเว็บนี้ด้วย **pywebview** แล้วคุยกับ Python ผ่าน API
- ฟอนต์ไทย: ติดตั้ง IBM Plex Sans Thai (หรือใช้ Noto Sans Thai เป็นตัวสำรอง)
